# HamidCognition Engine

> Historical source repository for the HamidCognition P/S/T and EUR/USD implementation lineage.

The canonical integrated project is **HamidCognition-Unified**. This repository is preserved as a historical source artifact and remains citable by its exact commit and path.

## Contents

- `hamid_cognition_engine.py` — P/S/T cognitive-state simulation engine.
- `hamid_cognition_transfer.json` — recorded state-transfer package.
- `simple_eurusd.py` — simplified EUR/USD analysis implementation.
- `eurusd_engine.py` — EUR/USD simulation engine using the P/S/T lineage.
- `run_eurusd.py` and `run_eurusd_real.py` — execution/reporting scripts.
- `cognitive_transfer_report.md` — historical transfer experiment report.

## Evidence boundary

These implementations are historical artifacts. Their existence does not establish scientific validation, production readiness, or live-trading profitability. Simulated results must not be presented as live-market evidence.

For current project status and canonical integration, use `HamidCognition-Unified`.
